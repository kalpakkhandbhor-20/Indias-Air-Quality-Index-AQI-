🌫️ India’s Air Quality Analysis Dashboard

Definition: The Air Quality Index (AQI) is a number that shows how clean or polluted the air is. This project analyzes AQI data of Indian cities to find pollution patterns, trends, and seasonal changes using an interactive Power BI dashboard.

📌 Project Overview
India faces serious air pollution problems, especially in big cities.
This dashboard helps users explore AQI data across 10 Indian cities from 2015 to 2020, compare pollution levels, and understand which pollutants and seasons affect air quality the most.

🎯 Objectives
- Compare AQI levels across different cities
- Identify the most and least polluted cities
- Analyze yearly AQI trends from 2015 to 2020
- Understand the seasonal impact on air quality
- Find the main pollutants driving poor AQI

📊 Dashboard Pages

Page 1: Overview
Shows key KPIs, city-wise AQI comparison, and the yearly AQI trend.

Page 2: Deep Dive
Shows pollutant-level analysis, seasonal patterns, and detailed city-wise breakdown.

🎛️ Interactive Features
Slicers for City, Year, and Season
Cross-filtering between visuals
Drill-down for detailed analysis

🔍 Key Insights
- PM2.5 emerged as a major contributor to air pollution in the analyzed data.
- Air quality varied across cities and seasons.
- The dashboard enables users to compare pollution levels across different years.
- Interactive filters make it easier to identify pollution patterns and explore individual cities.
